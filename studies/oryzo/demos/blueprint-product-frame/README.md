# Blueprint Product Frame

Brand-neutral demo of the Oryzo presentation grammar:

- warm dark stage
- large product wordmark
- dashed engineering frame
- circular product placeholder
- mono specification labels
- side model tab
- scroll-progress HUD

This is original CSS/JS. It does not contain Oryzo assets, fonts, source code,
models, textures, videos, or screenshots.

## Run

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```
