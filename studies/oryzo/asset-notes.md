# Asset Notes

## Original Asset Classes

The private Oryzo archive contains original-site material such as:

- Astro/JS/CSS runtime bundles.
- Adobe Typekit Halyard font files.
- DM Mono and Literata font files from the mirrored deployment.
- Product textures, environment maps, and BRDF textures.
- `.buf` geometry and animation data.
- `.sog` splat files.
- Rive file(s).
- Images, videos, thumbnails, and social-content media.
- Vimeo/third-party media references.

## Public Replacements

This public study replaces original assets with:

- Written teardown notes.
- Color and typography observations.
- Brand-neutral CSS/JS demo code.
- CSS shapes, gradients, and DOM geometry instead of Oryzo product
  models/textures.
- Low-resolution/compressed original-site reference media used only for
  commentary.
- Original per-effect recipes and minimal demos under `effects/` (all CSS/JS
  written for this repository).

## Excluded From Public Repo

Excluded:

- Original source bundles.
- Original images and videos.
- Original fonts.
- Original 3D model, animation, splat, Rive, and texture files.
- Full-page screenshot captures.
- Source-quality original-site recordings.
- Mirror manifests and raw network captures.

Any additional original-site media must stay small, low-resolution, and
commentary-oriented. Source-quality captures belong in the private workspace,
not this public repo.
